# Flipping Words

Telegram Mini App для изучения английских слов: готовые наборы A1–C2, темы и глаголы, свои колоды, несколько режимов тренировки, интервальные повторения и статистика. Работает без бэкенда — хостится на GitHub Pages, данные хранятся в Telegram CloudStorage (синхронизируются между устройствами).

## Возможности

- **Библиотека** — наборы по уровням A1–C2 (по 128–143 слова), 8 тематических наборов по 40 слов, 104 неправильных и 58 фразовых глаголов. Набор добавляется как обычная колода.
- **Тест на уровень** — по 5 слов на уровень начиная с A1, 4 из 5 — переход дальше. Можно проходить сколько угодно раз, история сохраняется.
- **Колоды и слова** — слово, перевод, пример, заметка; поиск по колоде.
- **Карточки** — тап переворачивает, свайп вправо «знаю», влево «не знаю». Озвучка произношения встроенным синтезатором речи.
- **Тест** — выбор правильного перевода из 4 вариантов.
- **Ввод** — написать английское слово по переводу; одна опечатка прощается, есть подсказка по буквам.
- **Пары** — игра на время: соединить 5 слов с переводами, 3 раунда.
- **Формы** — для неправильных глаголов: написать Past Simple и Past Participle.
- **Статистика** — тепловая карта активности, график выученных слов, слова по стадиям, самые трудные слова.
- **Интервальные повторения** — система Лейтнера: 0 → 1 → 3 → 7 → 14 → 30 → 60 → 120 → 240 дней. Ошибка возвращает слово в начало.
- **Направление** — EN → RU или RU → EN.
- **Поделиться колодой** — колода сжимается в ссылку `t.me/<бот>?startapp=…` (до ~20 слов, лимит Telegram 512 символов) или в текстовый код `FW1:…` для колод побольше.
- **Нативный вид Telegram** — цвета темы, MainButton/BackButton, вибрация.

## Локальный запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173. Вне Telegram данные хранятся в localStorage, кнопки рисуются обычными HTML-кнопками.

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub и запушь код в ветку `main`.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable:**
   `BOT_USERNAME` = username бота без `@` (нужен для ссылок «Поделиться»).
4. Каждый push в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`).
   Адрес будет вида `https://<твой-логин>.github.io/<репозиторий>/`.

## Подключение к боту

В [@BotFather](https://t.me/BotFather):

1. `/mybots` → выбери бота → **Bot Settings → Configure Mini App → Enable Mini App** → вставь адрес GitHub Pages.
   Это делает приложение «главным» для бота — ссылки `t.me/<бот>?startapp=…` будут открывать его сразу.
2. **Bot Settings → Menu Button** → тот же адрес, текст кнопки, например «Учить слова».

Готово: открой бота и нажми кнопку меню.

## Как добавить свои наборы в библиотеку

Наборы лежат в `src/data/**/*.txt`, по слову на строку: `word|перевод`, для неправильных глаголов `go|went|gone|идти`. Новый файл нужно прописать в `META` и `FILES` в `src/library.ts`.

## Структура

```
src/
  App.tsx            роутер-стек, анимации переходов, BackButton
  telegram.ts        обёртка над Telegram WebApp API
  store.ts           состояние + localStorage + синхронизация
  cloud.ts           Telegram CloudStorage (сжатие и нарезка на куски по 4 КБ)
  srs.ts             интервальные повторения
  share.ts           кодирование колоды в ссылку/код
  library.ts         каталог встроенных наборов
  data/              сами наборы слов (txt)
  screens/           экраны
  components/        UI-компоненты в стиле Telegram
```

## Ограничения подхода без сервера

- Нет push-напоминаний (боту для этого нужен свой код на сервере).
- CloudStorage: до 1024 ключей × 4096 символов — с учётом сжатия хватает на тысячи слов.
- Прогресс изучения при обмене колодой не передаётся — только сами слова.
